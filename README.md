# 🐂 Bulls and Cows

A simple **Bulls and Cows** number guessing game written in Python.

The computer generates a random 4-digit number, and your goal is to guess it.

## 🎮 How It Works

* 🐂 **Correct position** — The number is correct and in the correct position.
* 🐄 **Correct number, wrong position** — The number exists in the secret number but is in the wrong position.
* 🎯 Get all 4 numbers in the correct positions to win.

### Example

The secret number is:

```text
1587
```

Your guess:

```text
1852
```

Result:

```text
Correct position: 1
Correct number, wrong position: 2
```

## 🚀 How to Run

Make sure you have **Python 3** installed.

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Go into the project folder:

```bash
cd YOUR-REPOSITORY
```

Run the game:

```bash
python main.py
```

## 🕹️ Commands

Enter a **4-digit number** to make a guess.

You can also type:

```text
help
```

to exit the game.
